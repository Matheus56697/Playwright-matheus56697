# docs/prd/ — PRDs para testes manuais

Fonte dos PRDs usados para **criar ou cruzar suítes manuais** (Xray). Não misturar com Playwright/Cucumber da raiz.

Quando o usuário mandar um PRD no chat, **grave aqui** (não só no histórico da conversa).

| Arquivo | Conteúdo |
| --- | --- |
| `docs/prd/PRD-001-cerca-virtual.md` | Cerca Virtual (V1) |
| `docs/prd/T4-fluxo-alertas-colaborador.md` | T4 — alertas no Apponte.me Colaborador |

Tabela de testes gerada a partir do PRD segue `docs/AGENTS.md` (CSV/TSV, Action no imperativo).

**Cerca Virtual — lote:** a associação/remoção em lote fica descrita no PRD 001. **Não criar testes de lote** até o QA avisar no chat.
